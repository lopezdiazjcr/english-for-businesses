# English for Businesses

Landing de ventas con calculadora de precio por equipo. El botón lleva a WhatsApp con el cálculo ya escrito.

- Sitio: https://lopezdiazjcr.github.io/english-for-businesses/
- Todo lo editable (precios, descuentos, número de WhatsApp) está en el objeto `CFG` al final de `index.html`.
